# Badminton Chaos Features

## MVP
- [X] Excuse generator

## Phase 1 (Simple Additions)
- [ ] Match tracking: log player names, score, winner.
- [ ] Basic history list (local storage or JSON file).
- [ ] Share an excuse after each match result.

## Phase 2 (Intermediate Features)

- [ ] Player profiles (name, photo/avatar, win–loss record).
- [ ] Leaderboard (based on wins).
- [ ] Session tracking (multiple matches grouped by day/event).
- [ ] Fun stats: longest rally, “most excuses used,” etc.

## Phase 3 (Advanced/Complex)

- [ ] Authentication (so multiple people can use it).
- [ ] Cloud persistence (Postgres/Firestore).
- [ ] Badminton “queue” system (who’s next on court).
- [ ] Community features (invite friends, share matches).

## Phase 4 (Overengineer Chaos)

- [ ] Live match scoring with real-time updates (WebSockets).
- [ ] Integration with badminton scoring rules (21-point rally).
- [ ] AI-powered excuse generator (context-aware).
- [ ] Cross-club leaderboards, ELO-like rankings.
- [ ] Export stats to graphs/dashboards (Grafana/Datadog style).
- [ ] Mobile PWA or companion app.
